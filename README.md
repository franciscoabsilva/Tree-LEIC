# Tree LEIC
LEIC Family Tree

## Introduction
This project allows users to represent complex praxis family trees

## Requirements
Install Java FX 17.0.16 at https://gluonhq.com/products/javafx/ and place it in the same folder as the .sh code

## Run
To run the code simply clone the repository, go to the folder and type "./runAppFX.sh" in cmd.
